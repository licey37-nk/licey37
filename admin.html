🐍 Python (Pyodide, автономно в браузере)

Первый запуск загружает среду Python (~10 МБ) с CDN и кешируется браузером. Доступ к базе: словари USERS, POSTS, LISTINGS, QUANT_TXS, COMPLAINTS уже загружены из Supabase.

Terminal готов.

⚙️ C++17 (облачный запуск через Piston API)

Компиляция GCC 10.2 (C++17) на сервере Piston — без скачивания компиляторов. Для олимпиадных задач и алгоритмов.

Terminal готов.

⚡ JavaScript (мгновенная песочница)

Выполняется локально в изолированной функции. Доступ к базе: константы USERS, POSTS, LISTINGS, QUANT_TXS, COMPLAINTS, DB (все ключи Supabase).

Terminal готов.

🗄️ SQL-аналитика базы лицея

Таблицы: users, posts, listings, quant_txs, complaints, channels, reaction, friends, notifications, dms и все диалоги dm__…. Синтаксис: SELECT поля FROM таблица [WHERE поле =/!=/>/</>=/<=/LIKE значение] [ORDER BY поле [DESC]] [LIMIT n].

🎨 Конструктор виджетов HTML/CSS

Живое превью обновляется при вводе. Готовый код можно вставить в «Живое редактирование» → «➕ Блок» на портале.

🧬 JSON-инспектор ключей Supabase

Прямой просмотр всех ключей таблицы site_content. Клик по кнопке «Открыть» — полное значение. Удаление — с подтверждением.
