[Информатика | фибоначчи, последовательность, рекурсия, динамика] -> Числа Фибоначчи. Фибоначчи: f(1) = f(2) = 1, f(n) = f(n-1) + f(n-2): 1, 1, 2, 3, 5, 8, 13, 21.... Наивная рекурсия пересчитывает одно и то же (O(2ⁿ)). Итеративно: a, b = 1, 1; цикл n раз: a, b = b, a + b. Итеративный способ обязателен на ЕГЭ
[Информатика | кратность, последняя цифра, степень, цикличность] -> Условие кратности и последняя цифра. Последняя цифра степени повторяется циклом: 3, 9, 7, 1 для степеней тройки. Остаток от деления определяет позицию в цикле.. Последняя цифра 7^100: 7, 9, 3, 1 — цикл 4; 100 % 4 = 0 → цифра 1. Так решают задачи про огромные степени без калькулятора
[Информатика | двоичная система] -> В двоичной системе используются цифры 0 и 1. Перевод: 13 = 1101₂, так как 8+4+1=13. Для перевода из десятичной делим число на 2 и записываем остатки снизу вверх.
[Информатика | шестнадцатеричная система] -> В hex используются 0–9 и A–F, где A=10, F=15. Пример: 255₁₀ = FF₁₆. Одна hex-цифра кодирует ровно 4 бита, поэтому байт удобно записывать двумя hex-цифрами.
[Информатика | перевод битов] -> 1 байт = 8 бит; 1 Кбайт = 1024 байта; 1 Мбайт = 1024 Кбайта; 1 Гбайт = 1024 Мбайта. Пример: 2 Кбайта = 2048 байт = 16384 бита.
[Информатика | логическое и] -> Конъюнкция A и B истинна только когда оба выражения истинны. Обозначения: ∧, AND, «и». Пример: (x>5) и (x<10) истинно при x=7, но ложно при x=12.
[Информатика | логическое или] -> Дизъюнкция A или B ложна только когда оба выражения ложны. Обозначения: ∨, OR, «или». Пример: (x<0) или (x>100) истинно при x=-3 и при x=150.
[Информатика | логическое не] -> Инверсия меняет истинность выражения на противоположную: ¬A = NOT A. Пример: если A = «число чётное», то ¬A = «число нечётное». Приоритет: НЕ, затем И, затем ИЛИ.
[Информатика | таблица истинности] -> Для двух переменных возможны 4 набора значений: 00, 01, 10, 11. A∧B истинно лишь в 11; A∨B ложно лишь в 00. Число строк таблицы равно 2^n, где n — число переменных.
[Информатика | законы де моргана] -> НЕ(A И B) = (НЕ A) ИЛИ (НЕ B); НЕ(A ИЛИ B) = (НЕ A) И (НЕ B). Пример: ¬(x>3 ∧ x<8) равно x≤3 ∨ x≥8. Законы помогают упрощать сложные условия.
[Информатика | срезы списка] -> Срез a[start:stop:step] не включает stop. Пример: a=[10,20,30,40]; a[1:3]=[20,30]; a[::-1] переворачивает список. Отрицательные индексы считают с конца.
[Информатика | функция len] -> len() возвращает количество элементов. Пример: len([2,4,6])=3; len("информатика")=11. Для вложенного списка len считает только элементы верхнего уровня, а не все вложенные значения.
[Информатика | условие if] -> Конструкция if проверяет условие, elif — альтернативу, else — остальные случаи. Пример: if x>0: print("плюс") elif x==0: print("ноль") else: print("минус").
[Информатика | оператор %] -> Оператор % даёт остаток от деления. Пример: 17 % 5 = 2; 20 % 4 = 0. Проверка чётности: if n % 2 == 0. Остаток полезен в задачах на циклы и разряды числа.
[Информатика | функция int] -> int() преобразует значение в целое число. Пример: int("42")=42; int(3.9)=3 — дробная часть отбрасывается, а не округляется. Для округления используют round().
[Информатика | функция print] -> print() выводит данные на экран. Пример: print("Сумма:", a+b). По умолчанию значения разделяются пробелом, а после вывода добавляется перевод строки.
[Информатика | рекурсия] -> Рекурсия — вызов функцией самой себя с меньшей задачей. Обязательны базовый случай и правило перехода. Пример: факториал n! = n*(n-1)!, а 0! = 1.
[Информатика | алгоритм линейного поиска] -> Линейный поиск перебирает элементы по порядку до нахождения нужного. Сложность O(n). Пример: в списке [4,8,15] число 8 найдётся на втором шаге.
[Информатика | бинарный поиск] -> Бинарный поиск работает только в отсортированном массиве: сравнивает элемент с серединой и отбрасывает половину. Сложность O(log n). Пример: поиск в 1024 элементах — не более 10 шагов.
[Информатика | файлы и папки] -> Файл — именованная область данных на носителе, папка — контейнер для файлов и других папок. Пример: «referat.docx» лежит в папке «Школа». Полный путь показывает расположение файла.
[Информатика | расширение файла] -> Расширение указывает тип файла: .txt — текст, .jpg — изображение, .mp3 — звук, .mp4 — видео, .exe — программа. Пример: «photo.jpg» обычно является изображением в формате JPEG.
[Информатика | операционная система] -> Операционная система управляет устройствами компьютера, файлами, программами и интерфейсом пользователя. Примеры: Windows, Linux, macOS, Android. Без ОС пользователь не может удобно запускать программы.
[Информатика | алгоритм] -> Алгоритм — точная последовательность действий для решения задачи. Свойства: понятность, конечность, результативность, массовость. Пример: рецепт блинов — алгоритм приготовления блюда.
[Информатика | блок-схема] -> Блок-схема — графическая запись алгоритма. Овал — начало и конец, прямоугольник — действие, ромб — условие, параллелограмм — ввод или вывод. Стрелки показывают порядок выполнения.
[Информатика | линейный алгоритм] -> Линейный алгоритм выполняет действия строго по порядку, без условий и повторений. Пример: «ввести число → умножить на 2 → вывести результат». Каждый шаг выполняется один раз.
[Информатика | счётчик цикла] -> Счётчик — переменная, которая изменяется на каждом повторении цикла. Пример: i=0; while i<5: i+=1. После цикла i станет равным 5. Счётчик помогает подсчитать количество повторений.
[Информатика | накопитель суммы] -> Накопитель — переменная, в которой сохраняется результат повторяющихся вычислений. Пример: сумма чисел от 1 до 5: s=0; для каждого числа s+=число. Итог: s=15.
[Информатика | сумма элементов] -> Сумма элементов списка вычисляется функцией sum(a). Пример: sum([1,2,3])=6. Вручную: создай s=0 и в цикле прибавляй каждый элемент: s+=x. Это частая задача ОГЭ.
[Информатика | количество элементов] -> Количество элементов списка возвращает len(a). Пример: len([5,10,15])=3. Чтобы посчитать элементы по условию, используй цикл и счётчик: k+=1 при выполнении условия.
[Информатика | метод split] -> Метод split() разделяет строку на список по пробелам или указанному разделителю. Пример: "1 2 3".split() даст ["1","2","3"]. Чтобы получить числа, применяй int() к каждому элементу.
[Информатика | метод join] -> Метод join() соединяет элементы списка в строку. Пример: " ".join(["кот","дом"]) даст "кот дом". Разделитель указывается перед точкой: "-", "," или пробел.
[Информатика | функция abs] -> abs() возвращает модуль числа, то есть его расстояние от нуля. Пример: abs(-7)=7, abs(7)=7. Полезна при сравнении разницы чисел: abs(a-b)<0.001.
[Информатика | случайные числа] -> Модуль random создаёт случайные значения. Пример: import random; n=random.randint(1,10) даст целое число от 1 до 10 включительно. random.random() возвращает число от 0 до 1.
[Информатика | ошибка типов] -> Ошибка TypeError возникает при неверном типе данных. Пример: "5"+2 вызовет ошибку, потому что нельзя складывать строку и число. Исправление: int("5")+2 или "5"+str(2).
[Информатика | ошибка индекса] -> IndexError возникает при обращении к несуществующему индексу. Пример: a=[1,2,3]; a[3] вызовет ошибку, так как допустимы индексы 0, 1 и 2. Проверяй границы списка.
[Информатика | оператор ==] -> Оператор == сравнивает значения на равенство. Пример: 5==5 даёт True; "кот"=="кот" даёт True. Не путай с =, который присваивает значение переменной.
[Информатика | оператор !=] -> Оператор != проверяет неравенство. Пример: 4!=5 даёт True; 4!=4 даёт False. Часто используется в циклах: while answer != "стоп". Он противоположен оператору ==.
[Информатика | операторы сравнения] -> Основные операторы: > больше, < меньше, >= больше или равно, <= меньше или равно, == равно, != не равно. Пример: if x>=10: print("много"). Результат — True или False.
[Информатика | системы счисления] -> Система счисления — способ записи чисел. Десятичная использует 10 цифр, двоичная — 2, восьмеричная — 8, шестнадцатеричная — 16. Пример: 10₂ = 2₁₀.
[Информатика | перевод в двоичную] -> Для перевода делим число на 2 и записываем остатки в обратном порядке. Пример: 11: 11/2=5 ост.1; 5/2=2 ост.1; 2/2=1 ост.0; 1/2=0 ост.1. Ответ: 1011₂.
[Информатика | перевод из двоичной] -> Каждая двоичная цифра умножается на степень двойки. Пример: 1011₂ = 1*8+0*4+1*2+1*1 = 11. Разряды идут справа налево: 1, 2, 4, 8, 16.
[Информатика | логическая операция xor] -> XOR («исключающее ИЛИ») истинно, если значения различны. Обозначение: ⊕. Пример: 1⊕0=1, 1⊕1=0, 0⊕0=0. Используется в шифровании и проверке чётности.
[Информатика | импликация] -> Импликация A→B ложна только когда A истинно, а B ложно. Пример: «если идёт дождь, то дорога мокрая» ложно лишь при дожде и сухой дороге. В остальных случаях истинна.
[Информатика | эквивалентность] -> Эквивалентность A↔B истинна, когда значения совпадают: оба истинны или оба ложны. Пример: 1↔1=1, 0↔0=1, 1↔0=0. Её можно записать как (A и B) или (не A и не B).
[Информатика | граф] -> Граф состоит из вершин и рёбер, соединяющих вершины. Пример: города — вершины, дороги — рёбра. Степень вершины — число связанных с ней рёбер. Граф бывает ориентированным и неориентированным.
[Информатика | дерево] -> Дерево — связный граф без циклов. У него есть корень, ветви и листья. Пример: файловая система компьютера часто изображается деревом: диск — корень, папки — ветви, файлы — листья.
[Информатика | таблица истинности функции] -> Для логической функции с n переменными таблица содержит 2^n строк. Пример: для трёх переменных будет 8 строк. В каждой строке вычисляют значение выражения для конкретного набора значений.
[Информатика | адрес ячейки эт] -> В электронной таблице адрес ячейки состоит из буквы столбца и номера строки. Пример: B3 — столбец B, строка 3. Диапазон A1:C5 включает все ячейки от A1 до C5.
[Информатика | формула в эт] -> Формула в электронной таблице начинается со знака =. Пример: =A1+B1 складывает значения ячеек. =СРЗНАЧ(A1:A5) вычисляет среднее значение диапазона. При изменении данных формула пересчитывается.
[Информатика | абсолютная ссылка] -> Абсолютная ссылка фиксирует ячейку знаком $: $A$1. При копировании формулы ссылка не меняется. Пример: =B2*$A$1 умножает значения на одно и то же число из A1.
[Информатика | относительная ссылка] -> Относительная ссылка, например A1, изменяется при копировании формулы. Пример: формула =A1+B1 из строки 1 при копировании вниз станет =A2+B2. Это удобно для таблиц с повторяющимися вычислениями.
[Информатика | диаграмма] -> Диаграмма — графическое представление данных. Круговая показывает доли целого, столбчатая сравнивает значения, линейная отражает изменение во времени. Пример: расходы семьи удобно показать круговой диаграммой.
[Информатика | база данных] -> База данных — организованное хранилище информации. Таблица состоит из записей и полей. Пример: в базе учеников поля: фамилия, класс, оценка; одна строка — один ученик.
[Информатика | запрос к базе] -> Запрос выбирает данные по условию. Пример: «вывести всех учеников 9 класса». В электронных таблицах используют фильтр, а в SQL — команду SELECT с условием WHERE.
[Информатика | кодировка текста] -> Кодировка переводит символы в числа. В Unicode каждому символу соответствует уникальный код. Пример: латинская буква A имеет код 65. Один символ в UTF-8 может занимать 1–4 байта.
[Информатика | графическое изображение] -> Растровое изображение состоит из пикселей, векторное — из математических объектов: линий, фигур, кривых. Фото обычно растровое, логотип — часто векторный. При увеличении растр теряет качество.
[Информатика | глубина цвета] -> Глубина цвета — число бит на пиксель. При 1 бите возможны 2 цвета, при 8 битах — 256, при 24 битах — более 16 млн цветов. Пример: чёрно-белое изображение использует 1 бит на пиксель.
[Информатика | объём изображения] -> Объём растрового изображения равен числу пикселей, умноженному на глубину цвета. Пример: 100×100 пикселей при 8 битах занимает 10 000 байт, то есть около 9,77 Кбайт.
[Информатика | звук в цифровой форме] -> Звук оцифровывают через частоту дискретизации и глубину кодирования. Пример: 44,1 кГц означает 44 100 измерений в секунду. Чем выше частота и глубина, тем точнее звук и больше файл.
[Информатика | сжатие данных] -> Сжатие уменьшает объём файла. Без потерь сохраняются все данные, например ZIP; с потерями часть информации удаляется, например JPEG или MP3. Пример: архив уменьшает текстовые файлы.
[Информатика | алгоритм евклида] -> Алгоритм Евклида находит НОД двух чисел: заменяет большее число на остаток от деления до получения нуля. Пример: НОД(48,18): 48 mod 18=12, 18 mod 12=6, НОД=6.
[Информатика | простое число] -> Простое число имеет ровно два делителя: 1 и само себя. Примеры: 2, 3, 5, 7, 11. Число 1 не является простым. Проверка: пробуй делители до квадратного корня из числа.
[Информатика | чётность числа] -> Число чётное, если остаток от деления на 2 равен 0: n%2==0. Нечётное: n%2!=0. Пример: 8 чётное, 9 нечётное. Это базовая проверка во многих задачах программирования.
[Информатика | факториал] -> Факториал n! — произведение всех целых чисел от 1 до n. Пример: 5!=1*2*3*4*5=120. По определению 0!=1. Факториал быстро растёт: 10!=3 628 800.
[Информатика | числа фибоначчи] -> Числа Фибоначчи: каждое следующее равно сумме двух предыдущих. Последовательность: 1, 1, 2, 3, 5, 8, 13. Формула: F(n)=F(n-1)+F(n-2). Первые два значения задают начало.
[Информатика | перебор вариантов] -> Перебор проверяет все возможные варианты решения. Пример: чтобы найти пароль из двух цифр, проверяют 00–99. Метод надёжен, но может быть медленным при большом числе вариантов.
[Информатика | жадный алгоритм] -> Жадный алгоритм на каждом шаге выбирает локально лучший вариант. Пример: при сдаче монетами сначала берут самую крупную. Он быстр, но не всегда даёт оптимальный результат.
[Информатика | сложность алгоритма] -> Сложность показывает, как растёт время работы при увеличении данных. O(1) — постоянно, O(n) — линейно, O(n²) — квадратично. Пример: перебор всех пар элементов обычно имеет сложность O(n²).
[Информатика | рекурсия и цикл] -> Рекурсия вызывает функцию саму на себя, цикл повторяет блок кода. Факториал можно записать обоими способами. Рекурсия удобна для деревьев, цикл часто экономнее по памяти.
[Информатика | отладка программы] -> Отладка — поиск и исправление ошибок. Используй вывод переменных через print, проверяй граничные случаи и читай сообщение об ошибке. Пример: если цикл не заканчивается, проверь условие и изменение счётчика.
[Информатика | логическая ошибка] -> Логическая ошибка не вызывает сбой, но даёт неверный результат. Пример: вместо s+=i написано s=i. Программа работает, но сумма будет неправильной. Проверяй результат на простом примере.
[Информатика | инкапсуляция] -> Инкапсуляция — объединение данных и методов в объекте с ограничением прямого доступа к внутренним данным. Пример: у объекта «банковский счёт» баланс изменяется только через методы пополнения и списания.
[Информатика | http и https] -> HTTP передаёт данные между браузером и сайтом, HTTPS добавляет шифрование. Пример: адрес https:// означает защищённое соединение. HTTPS защищает пароли и личные данные от перехвата в открытой сети.
[Информатика | ip-адрес] -> IP-адрес — уникальный идентификатор устройства в сети. IPv4 состоит из четырёх чисел от 0 до 255: 192.168.1.1. IPv6 длиннее и записывается шестнадцатеричными группами.
[Информатика | dns] -> DNS переводит понятное имя сайта в IP-адрес. Пример: при вводе example.com браузер узнаёт адрес сервера через DNS-сервер. Без DNS пришлось бы запоминать числовые адреса сайтов.
[Информатика | url адреса] -> URL — адрес ресурса в интернете. Структура: протокол, домен, путь, параметры. Пример: https://site.ru/page?id=5: протокол https, домен site.ru, путь /page, параметр id=5.
[Информатика | электронная почта] -> Электронная почта позволяет отправлять сообщения и файлы по адресу вида имя@домен. Пример: ivan@mail.ru. В письме есть поля «Кому», «Тема», текст и возможные вложения.
[Информатика | парольная безопасность] -> Надёжный пароль длинный, уникальный и содержит буквы разного регистра, цифры и символы. Пример: лучше использовать фразу из 12+ символов. Не используй дату рождения или одно слово.
[Информатика | фишинг] -> Фишинг — попытка получить пароль, код или данные через поддельные сайты и письма. Признаки: срочность, ошибки, подозрительная ссылка. Пример: письмо «срочно подтвердите пароль» может быть мошенничеством.
[Информатика | вирус и вредоносная программа] -> Вредоносная программа может красть данные, шифровать файлы или показывать рекламу. Пример: троян маскируется под полезную программу. Защита: обновления, антивирус, осторожность с вложениями и ссылками.
[Информатика | резервное копирование] -> Резервная копия — дубликат важных файлов на другом носителе или в облаке. Правило 3-2-1: три копии, два разных носителя, одна копия вне дома. Пример: фото хранят на ПК и в облаке.
[Информатика | алгоритм шифрования] -> Шифрование превращает понятный текст в защищённый с помощью ключа. Пример: сдвиг каждой буквы на 3: «А» становится «Г». Современные методы используют сложные математические преобразования и ключи.
[Информатика | метод count] -> Метод count() считает вхождения элемента. Пример: "ананас".count("а")=3; [1,2,2,3].count(2)=2. Для строки аргумент — символ или подстрока, для списка — элемент.
[Информатика | метод find] -> Метод find() возвращает индекс первого вхождения подстроки или -1, если её нет. Пример: "информатика".find("мат")=4. Это удобно для поиска слова в тексте.
[Информатика | метод replace] -> Метод replace(a,b) заменяет все вхождения a на b. Пример: "кот-дом".replace("-"," ") даст "кот дом". Исходная строка не меняется: результат нужно сохранить в переменной.
[Информатика | метод strip] -> Метод strip() удаляет пробелы и другие указанные символы с концов строки. Пример: " привет ".strip() даст "привет". Для удаления только слева используют lstrip, только справа — rstrip.
[Информатика | метод startswith] -> Метод startswith() проверяет, начинается ли строка с указанного текста. Пример: "информатика".startswith("инф") даёт True. Похожий метод endswith() проверяет окончание строки.
[Информатика | функция type] -> type() показывает тип значения или переменной. Пример: type(5) — int, type("текст") — str, type(2.5) — float, type([1,2]) — list. Это помогает находить ошибки типов.
[Информатика | преобразование типов] -> int() делает целое число, float() — дробное, str() — строку. Пример: int("7")=7; float("2.5")=2.5; str(9)="9". Неверное преобразование, например int("abc"), вызовет ошибку.
[Информатика | аргумент функции] -> Аргумент — значение, которое передаётся в функцию. Пример: def privet(name): print("Привет,", name). Вызов privet("Аня") выведет «Привет, Аня». Аргументы записывают в скобках.
[Информатика | двоичная система, перевод] -> Двоичное число 1011₂ = 1·8+0·4+1·2+1·1 = 11₁₀. Перевод из десятичной: делим на 2 и собираем остатки снизу вверх. 1 байт = 8 бит, максимальное значение байта 255 (11111111₂). N бит кодируют 2^N значений. Шестнадцатеричная система использует цифры 0–9 и A–F.
[Информатика | алгоритм сортировки, быстрая сортировка] -> Быстрая сортировка (quicksort) выбирает опорный элемент, разбивает массив на меньшие и большие, рекурсивно сортирует части. Средняя сложность O(n log n), худшая O(n²) при неудачном выборе опоры. Сортировка слиянием гарантирует O(n log n), но требует O(n) памяти. Пузырьковая сортировка — O(n²).
[Информатика | сложность алгоритма, o-нотация] -> O-нотация описывает рост времени работы при увеличении входа n. O(1) — константа (доступ к элементу массива), O(log n) — бинарный поиск, O(n) — линейный проход, O(n log n) — хорошие сортировки, O(n²) — вложенные циклы. Пример: бинарный поиск в массиве из 1 млн элементов требует ~20 сравнений.
[Информатика | графы, алгоритм дейкстры] -> Алгоритм Дейкстры находит кратчайшие пути от вершины до всех остальных во взвешенном графе с неотрицательными весами. Работает через очередь с приоритетом: каждый раз извлекается вершина с минимальным расстоянием. Сложность O((V+E)log V) с двоичной кучей. Не работает при отрицательных рёбрах — там нужен Беллман–Форд.
[Информатика | кодирование звука, оцифровка] -> Объём звука: I = f·b·t·k, где f — частота дискретизации (Гц), b — глубина кодирования (бит), t — время (с), k — число каналов (моно 1, стерео 2). Пример: 1 канал, 8 кГц, 16 бит, 30 с: 8000·16·30 = 3 840 000 бит = 480 Кбайт.
[Информатика | объём изображения, растровый рисунок] -> Память картинки: I = W·H·b, где W·H — число пикселей, b — бит на пиксель. Цветов N = 2^b: 256 цветов = 8 бит. Пример: 640×480 при 8 бит = 307 200 байт = 300 Кбайт. Уменьшение палитры вдвое уменьшает файл на 1 бит на пиксель.
[Информатика | скорость передачи данных] -> Объём = скорость × время. Скорость 512 Кбит/с = 64 Кбайта/с (делим на 8!). Файл 2 Мбайта при 4 Мбит/с: 2·1024 Кбайт / 512 Кбайт/с = 4 с. Внимание: биты и байты не путать — в заданиях ЕГЭ любят разницу в 8 раз.
[Информатика | графы, деревья] -> Граф — вершины и рёбра; дерево — граф без циклов. Число рёбер полного графа из n вершин: n(n−1)/2 (каждая с каждой). Степень вершины — число её рёбер; сумма степеней всегда чётна (задача о рукопожатиях). Путь в дереве единственный.
[Информатика | стек и очередь] -> Стек — LIFO: последний пришёл, первый ушёл (стопка тарелок); операции push и pop. Очередь — FIFO: первый пришёл, первый ушёл (очередь в столовой). Рекурсия использует стек вызовов — отсюда переполнение при большой глубине.
[Информатика | excel формулы] -> СУММ(A1:A10) — сумма диапазона; СРЗНАЧ — среднее; МАКС/МИН; ЕСЛИ(A1>5; «да»; «нет») — условие; СЧЁТЕСЛИ(A1:A10; «>5») — подсчёт по условию. Формула начинается с =. Диапазон A1:A10 — столбец A, строки 1–10.
[Информатика | excel абсолютные ссылки] -> Относительная ссылка B2 при копировании меняется (B3, B4...), абсолютная $B$2 — нет (доллар «замораживает»). $B2 — заморожен столбец, B$2 — строка. В задачах на адресацию смешанные ссылки дают таблицу умножения.
[Информатика | исполнитель робот чертёжник] -> Исполнитель ходит по полю по командам. Робот закрашивает клетки и проверяет стены (сверху свободно/занято). Чертёжник понимает Сместиться на (x, y); повторение — нумерованный цикл «н раз». Задача: найти все команды, дающие один конечный путь, — сложи смещения.
[Информатика | палиндром число, задача] -> Число-палиндром читается одинаково с двух сторон: 121, 1331. Проверка: перевести в строку и сравнить s == s[::-1]. Реверс числа арифметически: while n > 0: rev = rev*10 + n%10; n //= 10; затем rev == n0.
[Информатика | перебор делителей, простые числа] -> Простое число делится только на 1 и себя: 2, 3, 5, 7, 11, 13... Проверка перебором до √n: for d in range(2, int(n**0.5)+1): if n % d == 0: составное. Корень — потому что делители идут парами. 1 не простое и не составное.
[Информатика | кодирование символов, длина сообщения] -> Если каждый символ кодируется K байтами, текст в N символов занимает N·K байт; при смене кодировки с 16-бит на 8-бит объём уменьшается вдвое. Пример: сообщение из 40 символов по 2 байта = 80 байт = 640 бит.
[Информатика | html основа страницы] -> Каркас: <!DOCTYPE html>, <html>, <head> с <title>, <body> с содержимым. Заголовки <h1>–<h6>, абзац <p>, ссылка <a href="url">, картинка <img src="...">. Теги парные, кроме одиночных (<br>, <img>). В Код-песочнице Лицея HTML можно пробовать прямо в браузере.
[Информатика | система счисления егэ №14] -> Типовое задание: найти количество единиц в двоичной записи выражения типа 4^2020 + 2^2017 − 15. Приём: 4^k = 2^(2k) — это единица и нули; вычитание 15 = 1111₂ превращает хвост в единицы. Считай разряды аккуратно по степеням двойки.
[Информатика | разбор чисел егэ №16] -> Рекурсивные функции: F(n) = F(n−1)·n и т.п. — подставляй по цепочке от базового случая, не считай в голове всё сразу. Табличка значений F(1), F(2)... спасает. Внимание: условие if n > 1 меняет ветку вычисления.
[Информатика | обработка массива егэ] -> Задачи «найти среднее/максимум среди элементов с условием»: цикл по массиву + счётчик + аккумулятор. Среднее только чётных: sum_even / count_even — оба считай в одном цикле. Внимание к целочисленному делению при выводе.
[Информатика | файлы и каталоги] -> Каталог — «папка», путь вида D:\Школа\ОГЭ\пример.docx: диск, вложенные папки, имя с расширением. Полный путь от корня, относительный — от текущей папки (../ — на уровень выше). Маска *.txt отбирает все текстовые файлы.
[Информатика | анализ диаграмм егэ] -> Круговая диаграмма показывает доли от целого (сумма всех секторов = 100%); столбчатая — точные значения по категориям. Задание: по таблице чисел определить, какая диаграмма соответствует. Приём: сравни отношения (больше/меньше, ровно половина).
[Информатика | кодировка, unicode, utf-8] -> Компьютер хранит текст как числа. Старая таблица ASCII кодировала 128 символов, KOI-8 и Windows-1251 — кириллицу по-своему, из-за чего буквы «ехали». Unicode присвоил номер каждому символу мира, а UTF-8 экономно кодирует его байтами. Именно поэтому эмодзи одинаково видны на любом устройстве.
[Информатика | стек, очередь, структура данных] -> Стек работает по принципу LIFO — последним пришёл, первым ушёл: стопка тарелок. Очередь — FIFO, как касса в магазине. Стек нужен для отмены действий и вызовов функций, очередь — для печати документов и обработки задач. Обе структуры строятся на списках.
[Информатика | граф, вершина, ребро] -> Граф — набор вершин, соединённых рёбрами. Схема метро, друзья в соцсети и карты дорог — всё графы. Дерево — граф без циклов: файловая система и родословная. Обход в ширину ищет кратчайший путь по числу рёбер, обход в глубину уходит вглубь, как в лабиринте у стены.
[Информатика | excel, формула, электронная таблица] -> В электронных таблицах адрес ячейки состоит из буквы столбца и номера строки: A1, B7. Формула начинается со знака равенства: =A1+B1. Знак $ фиксирует ссылку ($A$1) при копировании. Функции СУММ, СРЗНАЧ, ЕСЛИ закрывают большинство задач ОГЭ по таблицам.
[Информатика | ip-адрес, протокол, пакет] -> IP-адрес — уникальный номер устройства в сети из четырёх чисел 0–255 (192.168.1.1). Данные режутся на пакеты, каждый летит своим маршрутом и собирается у получателя. Протокол TCP гарантирует доставку, HTTP передаёт веб-страницы, DNS превращает имя сайта в IP-адрес.
[Информатика | рекурсия, базовый случай, факториал] -> Рекурсия — функция, которая вызывает саму себя до достижения базового случая. Факториал: 5! = 5 × 4!. Без базового случая программа падает от переполнения стека. Рекурсию удобно применять к деревьям и фракталам, но глубина вызовов ограничена памятью.
[Информатика | ооп, объект, наследование] -> Объектно-ориентированное программирование строит программу из объектов: у них данные (свойства) и поведение (методы). Три кита: наследование — класс берёт поля родителя; инкапсуляция — данные спрятаны за методами; полиморфизм — один интерфейс, разные реализации. Класс — чертёж, объект — дом по нему.
[Информатика | база данных, sql, запрос] -> База данных хранит информацию в таблицах: строки — записи, столбцы — поля. Язык SQL выбирает данные: SELECT name FROM students WHERE grade = 8. Запрос с JOIN соединяет таблицы, ORDER BY сортирует, COUNT считает. Первичный ключ однозначно определяет запись.
[Информатика | погрешность, измерение, цена деления] -> Любое измерение имеет погрешность: она равна половине цены деления прибора. Линейка с делениями в миллиметр измеряет с точностью до полмиллиметра. Результат записывают с верными цифрами: 25,0 ± 0,5 мм. В задачах ЕГЭ по физике погрешность важна не меньше самого ответа.
[Информатика | сжатие данных, архив, избыточность] -> Сжатие убирает избыточность данных. Алгоритм RLE заменяет повторы: пять букв А и две Б превращаются в запись 5А2Б. Словарные методы ZIP переиспользуют повторяющиеся куски. JPEG и MP3 — сжатие с потерями: они выбрасывают то, что человек плохо воспринимает. Архивация экономит трафик и место на диске.
[Информатика | тестирование, отладка, баг] -> Тестирование проверяет, что программа работает, отладка ищет причину, когда не работает. Виды ошибок: синтаксические (ловит компилятор), логические (неверный результат) и времени выполнения (деление на ноль). Точка останова и печать промежуточных значений — первые инструменты отладчика.
[Информатика | qr-код, матричный код, помехоустойчивость] -> QR-код хранит данные в двумерной матрице чёрных и белых модулей. Три угловых квадрата служат ориентирами, а помехоустойчивость позволяет прочитать код, даже если стёрто до 30% площади. В QR помещается несколько тысяч символов. Код цифрового паспорта Лицея №37 работает по этому же принципу.
[Информатика | wi-fi, bluetooth, беспроводная связь] -> Wi-Fi передаёт данные на десятки метров с высокой скоростью, Bluetooth — на близком расстоянии с малым расходом энергии: наушники, фитнес-браслеты. Wi-Fi работает на частотах 2,4 и 5 ГГц: чем выше частота, тем быстрее связь, но хуже она проходит через стены.
[Программирование | git, коммит и ветка] -> Git — распределённая система контроля версий. git commit фиксирует снимок изменений с хешем SHA-1; git branch создаёт указатель на коммит; git merge объединяет ветки. Конфликт возникает при изменении одних строк в обеих ветках и решается вручную. git push отправляет коммиты в удалённый репозиторий.
[Программирование | sql, join] -> INNER JOIN возвращает строки, где условие соединения выполнено в обеих таблицах. LEFT JOIN сохраняет все строки левой таблицы, подставляя NULL при отсутствии совпадений. Пример: SELECT * FROM orders LEFT JOIN users ON orders.user_id=users.id вернёт и заказы без пользователя (NULL в полях users).
[Программирование | регулярные выражения, квантификаторы] -> Регулярное выражение описывает шаблон строки. \d — цифра, \w — буква/цифра/_, . — любой символ, * — 0 и более, + — 1 и более, ? — 0 или 1, {n,m} — от n до m повторов. ^ и $ — начало и конец строки. Пример: ^\d{3}-\d{2}-\d{4}$ соответствует формату SSN 123-45-6789.
