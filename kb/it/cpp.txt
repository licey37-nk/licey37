[C++ | структура программы, main] -> Любая программа C++: #include <iostream>, затем int main() { ...; return 0; } — с неё начинается выполнение. Точка с запятой после каждой команды, тело в фигурных скобках. Без main программа не собирается.
[C++ | cout cin, ввод вывод] -> Вывод: cout << x << endl; ввод: cin >> x >> y. endl или '\n' переводит строку. Для точности double: cout << fixed << setprecision(2) << x (нужен <iomanip>). cin >> пропускает пробелы и читает до пробела.
[C++ | типы данных, int long long] -> int — целые до ~2·10⁹; long long — до ~9·10¹⁸ (для 10¹⁰ уже нужен он!); double — дробные; char — символ; bool — true/false. Переполнение int — частая ошибка ЕГЭ: 100000·100000 не влезает в int.
[C++ | vector, динамический массив] -> vector<int> a(n); — массив на n элементов; a.push_back(x) добавляет в конец; a.size() — длина; a.pop_back() удаляет последний. Нужен #include <vector>. Вектор сам расширяется — в отличие от статического int a[100].
[C++ | string, строки] -> string s = "привет"; s.size() или s.length() — длина; s.substr(0, 3) — подстрока; s += "!" добавляет в конец; s[i] — символ по индексу. Сравнение s1 == s2 работает как ожидается (в отличие от C-массивов).
[C++ | функции, прототип] -> Функция: int sum(int a, int b) { return a + b; } — тип возвращаемого значения, имя, параметры. Вызов: int r = sum(2, 3). void — функция без результата. Параметры передаются копией; ссылка int& x позволяет менять оригинал.
[C++ | sort, сортировка] -> sort(a.begin(), a.end()) сортирует вектор по возрастанию (нужны <algorithm> и <vector). По убыванию: sort(a.begin(), a.end(), greater<int>()). Для массива: sort(a, a + n). Сложность O(n log n) — быстро даже на миллионе элементов.
[C++ | двумерный массив, матрица] -> int a[10][10]; — таблица 10×10, обращение a[i][j]. Обход: for (int i = 0; i < n; i++) for (int j = 0; j < m; j++) cin >> a[i][j]. Первый индекс — строка, второй — столбец. vector<vector<int>> — динамический вариант.
[C++ | инкремент декремент] -> i++ (постфикс) и ++i (префикс) увеличивают на 1, i-- уменьшает. Разница видна в выражении: x = i++ сначала присваивает старое значение, ++i — сначала увеличивает. В цикле for обычно пишут i++.
[C++ | цикл for синтаксис] -> for (int i = 0; i < n; i++) { ... } — инициализация; условие; шаг. Выполняется пока условие истинно. Нумерация с 0 до n-1 — классика массивов. Цикл в цикле перемножает числа повторений.
[C++ | цикл while] -> while (условие) { ... } повторяет тело, пока условие истинно; do { ... } while (условие) выполняет тело хотя бы раз. Пример: разбор цифр числа while (n > 0) { s += n % 10; n /= 10; }.
[C++ | условие if else] -> if (x > 0) { ... } else if (x == 0) { ... } else { ... }. Логические операторы: && (И), || (ИЛИ), ! (НЕ). Сравнение — двойное равно ==, одиночное = это присваивание — частая ошибка!
[C++ | операции % и /] -> % даёт остаток: 17 % 5 = 2; / для целых отбрасывает дробь: 17 / 5 = 3, но 17.0 / 5 = 3.4. Чётность: n % 2 == 0. Последняя цифра: n % 10. Для отрицательных % может дать отрицательный результат.
[C++ | компиляция g++] -> Программа в файле main.cpp компилируется: g++ main.cpp -o program, запуск: ./program. С флагом -O2 ускоряет; -std=c++17 включает современный стандарт. Ошибки компиляции показывают номер строки — читай первую ошибку.
[C++ | ссылки, передача в функцию] -> void add(int& x) { x++; } — амперсанд делает параметр ссылкой: меняется оригинал, а не копия. Без & функция работает с копией. Большие структуры (vector, string) передают по const& для скорости: void f(const vector<int>& a).
[C++ | комментарии] -> Однострочный комментарий: // текст до конца строки. Многострочный: /* текст */. Комментарии игнорируются компилятором — нужны людям. Хорошее правило: объяснять «почему», а не пересказывать код.
[C++ | рекурсия] -> Рекурсия — функция вызывает себя: int fact(int n) { if (n <= 1) return 1; return n * fact(n - 1); }. Обязательно базовое условие, иначе переполнение стека (stack overflow). Глубина ограничена — обычно ~10⁵ вызовов.
[C++ | отличие от python] -> Главное отличие от Python: в C++ типы объявляются явно (int x = 5), команды заканчиваются точкой с запятой, блоки в фигурных скобках вместо отступов. C++ быстрее и строгий по типам, Python короче и прощает ошибки. Логика алгоритмов одинакова.
[C++ | компиляция, g++, main] -> C++ — компилируемый язык: код превращается в машинный код до запуска, поэтому программы быстрые. Любая программа начинается с функции main. Сборка: g++ main.cpp -o program, запуск ./program. C++ стоит на весь софт, где важна скорость: игры, браузеры, драйверы, автопилот КамАЗа.
[C++ | переменные, типы, int double] -> Тип определяет размер и смысл данных: int — целые (4 байта), double — дробные, char — символ, bool — истина/ложь, long long — большие целые до 9×10^18. Переполнение int — частый источник ошибок в олимпиадах: 2×10^9 + 2×10^9 уже не влезает. Размер типа уточняет sizeof.
[C++ | vector, stl, динамический массив] -> vector — динамический массив из стандартной библиотеки: vector<int> v; v.push_back(5); размер узнаёт v.size(), доступ v[0]. Он сам растёт по мере добавления. Сортировка одной строкой: sort(v.begin(), v.end()). Вектор удобнее сырого массива и почти так же быстр.
[C++ | map и set, контейнеры, поиск] -> map хранит пары ключ-значение отсортированно: map<string, int> score; score["Аня"] = 95. set хранит только уникальные значения и отвечает на вопрос «есть ли элемент» за O(log n). Оба построены на дереве. Для простого подсчёта частот map<string,int> — стандартное решение.
[C++ | строки, string, getline] -> string из STL умеет складывать (+), сравнивать, искать подстроку (find), заменять и выдавать длину (size()). Ввод строки с пробелами: getline(cin, s). Символ по индексу: s[0]. Первая буква в верхний регистр: s[0] = toupper(s[0]). C-строки char[] — легаси, в школьных задачах хватит string.
[C++ | циклы, for, while] -> Классический for (int i = 0; i < n; i++) повторяет блок с счётчиком. while крутится, пока условие истинно, do-while выполнится хотя бы раз. Диапазонный for по вектору: for (int x : v). Инкремент i++ и префиксный ++i дают одинаковый результат в одиночном выражении.
[Информатика | c++, cout, cin, include, main] -> C++: первая программа. Скелет C++: #include <iostream>, int main(), std::cout << 'Привет'; return 0. Ввод — std::cin >> x.. using namespace std; избавляет от префикса std::. endl или ' ' — перевод строки. Точка с запятой обязательна после каждого оператора
[Информатика | c++, int, long long, double, тип, переполнение] -> C++: типы данных. Типы C++: int — до ~2 млрд, long long — до ~9·10¹⁸, double — дробные, char — символ, bool — истина/ложь.. Переполнение int — частая ошибка: при умножении больших чисел используй long long. Точность double около 15 знаков. sizeof(int) = 4 байта
[Информатика | c++, if, for, while, цикл] -> C++: условие и циклы. Синтаксис C++: if (x > 0) { ... }, for (int i = 0; i < n; i++) { ... }, while (условие) { ... }.. Скобки {} обязательны для блоков из нескольких операторов. i++ увеличивает на 1. break и continue работают как в Python
[Информатика | c++, массив, vector, индекс, размер] -> C++: массивы и vector. Массив: int a[100]; вектор: vector<int> a(n) — размер можно менять. Индексация с нуля.. vector: a.push_back(x) — добавить, a.size() — длина, a.pop_back() — удалить последний. Инициализация нулями: vector<int> a(n, 0)
[Информатика | c++, функция, тип возврата, void, параметры] -> C++: функции. Функция в C++ объявляется с типом возврата: int sum(int a, int b) { return a + b; }. void — без возврата.. Прототип объявляют до main, если функция определена ниже. Параметры передаются по значению: функция работает с копией
[Информатика | c++, string, строка, size, substr] -> C++: строки. Строка C++: string s = 'привет'; длина s.size(), конкатенация s + '!', сравнение s == 'код'.. s.substr(0, 3) — первые 3 символа; s[i] — символ по индексу; s.find('ко') — позиция подстроки или npos. Чтение строки с пробелами: getline(cin, s)
[Информатика | c++, sort, algorithm, сортировка, greater] -> C++: sort и algorithm. sort(a.begin(), a.end()) сортирует вектор по возрастанию. Для убывания: greater<int>().. Подключить #include <algorithm>. sort работает за O(n log n). min_element и max_element дают итераторы на минимум и максимум
[Информатика | c++, егэ, перебор, long long, файл] -> C++: решение задач ЕГЭ. В C++ для ЕГЭ читают данные через while (cin >> x), считают циклом; главное — long long для больших произведений.. Шаблон перебора отрезка: for (int i = a; i <= b; i++) { ... }. Делимость: i % 3 == 0. Вывод: cout << k << ' ' << s
[Информатика | c++ цикл for] -> В C++ цикл for имеет вид for (int i=0; i<n; i++) { ... }. Он выполняется, пока условие i<n истинно. Пример вывода чисел 0–4: for(int i=0;i<5;i++) cout<<i;
[Информатика | c++ подключение библиотеки] -> В C++ библиотеки подключают через #include. Пример: #include <iostream> даёт доступ к cin и cout. Для вектора используют #include <vector>, для математики — <cmath>.
[Информатика | c++ ввод и вывод] -> В C++ cin читает данные, cout выводит их. Пример: int a; cin>>a; cout<<a*2;. Не забудь #include <iostream> и using namespace std; либо пиши std::cin и std::cout.
[Информатика | c++ типы данных] -> Основные типы C++: int — целое число, double — дробное, char — символ, bool — истина или ложь. Пример: int age=15; double pi=3.14; char c='A'; bool ok=true.
[Информатика | c++ условие if] -> В C++ условие записывают в круглых скобках: if (x>0) { ... } else { ... }. Пример: if (x%2==0) cout<<"чётное"; else cout<<"нечётное";. Фигурные скобки обязательны для нескольких команд.
[Информатика | c++ цикл while] -> Цикл while в C++ повторяет код, пока условие истинно. Пример: int i=1; while(i<=5){ cout<<i; i++; }. Без i++ возникнет бесконечный цикл. Условие проверяется перед каждым повторением.
[Информатика | c++ массив] -> Массив в C++ хранит элементы одного типа. Пример: int a[5]={2,4,6,8,10};. Индексы начинаются с 0: a[0]=2, a[4]=10. Выход за границы массива опасен и может вызвать ошибку.
