[Python | словарь методы, keys, values, items] -> У словаря три главных метода: d.keys() — все ключи, d.values() — все значения, d.items() — пары. Пример: for k, v in d.items(): print(k, v). Проверка наличия ключа: 'a' in d — быстрее метода get для проверки.
[Python | str.format, форматирование] -> Метод format подставляет значения: 'Привет, {}!'.format('Аня') → «Привет, Аня!». Нумерация: '{0} + {1} = {2}'.format(2, 3, 5). Округление в выводе: '{:.2f}'.format(3.14159) → 3.14. Это предшественник f-строк.
[Python | break, continue, циклы] -> break мгновенно выходит из цикла, continue пропускает остаток тела и переходит к следующей итерации. Пример: поиск первого делителя — нашли, break; отбор чётных — нечётное, continue. Бесконечный while True выходят только break-ом.
[Python | вложенные циклы, таблица умножения] -> Вложенный цикл — цикл внутри цикла: внешний по строкам, внутренний по столбцам. Пример: for i in range(1, 4): for j in range(1, 4): print(i*j, end=' '). Полное число повторений — произведение: 3×3 = 9 итераций.
[Python | max min key, максимум по условию] -> Аргумент key меняет критерий: max(words, key=len) вернёт самое длинное слово; max(students, key=lambda s: s['ball']) — лучший по баллу. Без key сравниваются сами элементы. Для списка пар key=lambda p: p[1] берёт второй элемент.
[Python | join, сборка строки] -> join склеивает список в строку: ' '.join(['кот', 'пёс']) → «кот пёс»; ''.join(a) — без разделителя; ', '.join(map(str, nums)) — числа через запятую. Обратно: split режет строку в список. Все элементы должны быть str — иначе TypeError.
[Python | isdigit isalpha, проверка символов] -> s.isdigit() — строка только из цифр (для int(s) безопасно), s.isalpha() — только буквы, s.isalnum() — буквы и цифры. Пример валидации: if s.isdigit(): n = int(s) else: print('ошибка'). Пустая строка возвращает False.
[Python | обмен значениями, множественное присваивание] -> Python умеет менять значения без третьей переменной: a, b = b, a. Аналогично распаковка: x, y, z = 1, 2, 3 и a, *rest = [1, 2, 3] → rest = [2, 3]. Это короче классического tmp = a.
[Python | генератор списка с условием, фильтр] -> Условие в включении фильтрует: [x for x in range(20) if x % 3 == 0] → [0, 3, 6, 9, 12, 15, 18]. С if-else меняется значение: [x if x > 0 else 0 for x in nums]. Так на ЕГЭ решают отбор чисел с заданным свойством.
[Python | остаток от деления задачи, последняя цифра] -> Последняя цифра числа n — это n % 10; отбросить её — n // 10. Чётность — n % 2; кратность 5 — n % 5 == 0. Пример: сумма цифр 345 = 3 + 4 + 5 собирается циклом while n > 0: s += n % 10; n //= 10.
[Python | палиндром, проверка строки] -> Палиндром читается одинаково в обе стороны: s == s[::-1] — самая короткая проверка (казак, шалаш). Перед сравнением приводят к нижнему регистру: t = s.lower().replace(' ', ''). Альтернатива — два указателя с концов.
[Python | фибоначчи, ряд чисел] -> Ряд Фибоначчи: 1, 1, 2, 3, 5, 8, 13 — каждое число равно сумме двух предыдущих. Код: a, b = 1, 1; for i in range(n): print(a); a, b = b, a + b. Рост быстрый: 10-е число 55, 20-е — 6765.
[Python | факториал циклом] -> Факториал n! = 1·2·…·n, причём 0! = 1. Итеративно: p = 1; for i in range(2, n + 1): p *= i. Пример: 5! = 120. Есть и math.factorial(n). Рекурсия: f(n) = n * f(n-1) при базовом f(0) = 1.
[Python | сравнение float, погрешность] -> Из-за двоичного представления 0.1 + 0.2 = 0.30000000000000004, поэтому дробные сравнивают с допуском: abs(a - b) < 1e-9. Для денег считают в копейках (целыми). round(x, 2) округляет до двух знаков по правилам математики.
[Python | строки сравнение, регистр] -> Сравнение строк идёт по кодам символов: 'А' < 'Б', '2' < 'А' (цифры раньше букв), заглавные раньше строчных. Для корректного сравнения слов приводят оба к lower(): 'Яблоко'.lower() == 'яблоко'. Порядок важен при сортировке слов.
[Python | вложенные списки, матрица] -> Матрица — список списков: m = [[1, 2], [3, 4]]; обращение m[1][0] = 3. Обход: for row in m: for x in row. Создание нулевой матрицы n×m: [[0]*m for _ in range(n)] — но не [[0]*m]*n (тогда строки общие!).
[Python | counter, частота элементов] -> Частоту считают словарём: c = {}; for x in a: c[x] = c.get(x, 0) + 1. Самое частое: max(c, key=c.get). Готовый класс collections.Counter(a).most_common(3) даёт топ-3. Так ищут самое частое слово в тексте.
[Python | уникальные элементы с порядком] -> Убрать дубликаты, сохранив порядок: seen = set(); res = [x for x in a if not (x in seen or seen.add(x))]. Простой set(a) порядок ломает. Проверка «все уникальны»: len(set(a)) == len(a) — классическая задача ОГЭ.
[Python | сумма и произведение, accumulate] -> Сумма списка: sum(a); произведение через цикл p = 1; for x in a: p *= x. Среднее: sum(a) / len(a) (ошибка деления на ноль при пустом списке!). Модуль math.prod(a) перемножает целиком (Python 3.8+).
[Python | split с разделителем, обработка ввода] -> s.split() без аргумента режет по любым пробелам и убирает лишние; s.split(',') — по запятой, сохраняя пробелы. Несколько чисел в строке: a, b = input().split(); затем int(a), int(b). map(int, input().split()) — всё сразу в список.

[Программирование | рекурсия, факториал] -> Рекурсия — функция вызывает саму себя с меньшим аргументом до базового случая. Пример: factorial(n)=n·factorial(n−1), factorial(0)=1. Без базового случая — бесконечная рекурсия и переполнение стека. Глубина стека в Python по умолчанию ~1000 вызовов; рекурсию можно заменить итерацией или мемоизацией.
[Программирование | ооп, инкапсуляция] -> Инкапсуляция скрывает внутреннее состояние объекта и даёт доступ через методы. В Python приватность условна: атрибуты с _ или __ (name mangling). Пример: class BankAccount хранит баланс в self.__balance и меняет его только методами deposit/withdraw, проверяющими сумму. Наследование, полиморфизм и абстракция — остальные принципы ООП.
